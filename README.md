# Paradise Nursery — e-plantShopping

A React plant-shopping application for browsing indoor plants, adding plants to a shopping cart, adjusting quantities, and checking the cart total.

## Features
- Landing page with “Welcome To Paradise Nursery” and Get Started
- About Us page
- Three plant categories, with six plants in each category
- Add to Cart button disables after adding a plant
- Shared navigation for Home, Plants, and Cart
- Shopping cart with quantity controls, Delete, subtotal, total, and checkout alert
- Redux Toolkit cart state management

## Run the application
1. Install Node.js LTS.
2. In this project folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL displayed by Vite.

## Technologies
React, Vite, Redux Toolkit, React Redux, CSS.
